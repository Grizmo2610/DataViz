# MCP Server and Skill

DataViz ships an [MCP](https://modelcontextprotocol.io) server so AI assistants can analyze files, render charts, and export reports through tool calls. A matching skill teaches the assistant when and how to use those tools.

The server runs the same tools as the CLI but needs **no LLM API key**: the assistant is the LLM. Report text (summary, insights, recommendations) is generated by rules from the data.

## Install

```bash
pip install -e .          # installs the `dataviz-mcp` command
playwright install chromium   # only needed for PDF export
```

`mcp` 1.x and 2.x are both supported.

## Register the server

Claude Code:

```bash
claude mcp add dataviz -- dataviz-mcp
```

Claude Desktop or any client that uses a JSON config:

```json
{
  "mcpServers": {
    "dataviz": {
      "command": "dataviz-mcp"
    }
  }
}
```

If `dataviz-mcp` is not on the client's `PATH`, use the full path to the executable from your virtual environment (for example `/path/to/.venv/bin/dataviz-mcp`).

## Tools

| Tool | Purpose |
|------|---------|
| `inspect_dataset(file_path, sheet_name?, n_rows?)` | Schema, null counts, sample rows |
| `analyze_dataset(file_path, sheet_name?, sections?)` | Stats, nulls, correlation, time series, categorical distributions, outliers |
| `suggest_charts(file_path, sheet_name?)` | Chart specs that fit the data |
| `render_chart(file_path, chart_type, column?, x?, y?, group_by?, hue?, sheet_name?, out_dir?, include_vega_spec?)` | One chart saved as SVG |
| `export_report(file_path, output_format?, out_dir?, sheet_name?, lang?)` | Full report: `html`, `md`, `pdf`, `notebook` |

Files are written to `out_dir`, which defaults to `dataviz_output` in the server's working directory. Tools return absolute paths.

## Skill

`skills/dataviz/SKILL.md` describes the workflow for an assistant. Install it by copying the `skills/dataviz/` folder into your skills directory, for example:

```bash
cp -r skills/dataviz ~/.claude/skills/
```

The skill prefers the MCP tools and falls back to calling the Python functions or the CLI when the server is not registered.

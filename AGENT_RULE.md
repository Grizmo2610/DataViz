# Agent Rules - DataViz

These rules apply to agents working on this repository.

## Read first

- Read the top-level directory first.
- Read the relevant design files before editing code.
- Check `dataviz/tools/registry.json` before assuming a tool exists.

## Branching

- Use a dedicated branch after Phase 0.
- Do not merge into `main` without explicit instruction.

## Code

- Keep all names in English.
- Use Google-style docstrings for public functions and classes.
- Do not put generated tool code into core tool files.
- Keep side effects inside tools, not agents.

## Docs

- Update `ROADMAP.md` and `CHANGELOG.md` when a phase changes state.
- Keep JSON config files in plain JSON only.

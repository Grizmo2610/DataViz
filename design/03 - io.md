# 03 — Input, Output & Data Strategy

## Input Formats

| Format | Ghi chú |
|---|---|
| `.csv` | Auto-detect delimiter: `,` `;` `\t` |
| `.xlsx` | Multi-sheet support, chỉ định sheet qua `--sheet` |
| `.parquet` | Lazy read được hỗ trợ (polars) |

Hỗ trợ **nhiều file cùng lúc** — tự động join/merge trước khi phân tích (xem [Multi-file](#multi-file-support)).

---

## Output Formats

| Format | Engine | Flag |
|---|---|---|
| HTML | Plotly (interactive) | `--output html` |
| Markdown | Text + embedded base64 images | `--output md` |
| PDF | Matplotlib/Seaborn + WeasyPrint | `--output pdf` |
| Jupyter Notebook | nbformat + Plotly | `--output notebook` |

**Default:** `html`

```bash
dataviz data.csv                          # → HTML
dataviz data.csv --output pdf             # → PDF
dataviz data.csv --output notebook        # → .ipynb
dataviz data.csv --output md              # → Markdown
```

## Data Strategy

### Bước 1 — Sampling (hiểu schema)

```
read_sample(10–20 rows)
    │
    ▼
AI kiểm tra: đủ để hiểu schema chưa?
    ├── Đủ → tiếp tục
    └── Chưa đủ → read_sample(up to 100 rows tổng cộng)
```

Chart được vẽ từ sample này (nhanh, ít RAM).

### Bước 2 — Full-data pass (thống kê chính xác)

Các metrics cần toàn bộ dataset được tính qua **chunked/lazy processing** — không bao giờ load toàn bộ file vào RAM khi file lớn:

- `min`, `max`, `mean`, `median`, `std`
- `count`, `null_count`, `unique_count`
- Trend detection (time-series)
- Correlation matrix
- Outlier detection

---

## Scale Handling

| Scale | Row count | Strategy |
|---|---|---|
| Small | < 100k rows | Load toàn bộ vào memory |
| Medium | 100k – 1M rows | Chunked pandas hoặc polars lazy |
| Large | > 1M rows | polars lazy scan, streaming aggregations |

### Implementation chi tiết

```python
# readers/csv_reader.py — pseudocode

def get_read_strategy(file_path: str) -> str:
    """Xác định strategy đọc file dựa trên kích thước ước tính.

    Args:
        file_path: Đường dẫn file CSV.

    Returns:
        Strategy: "full", "chunked", hoặc "lazy".
    """
    size_mb = os.path.getsize(file_path) / (1024 * 1024)
    if size_mb < 50:       # < ~100k rows thường
        return "full"
    elif size_mb < 500:    # ~100k–1M rows
        return "chunked"
    else:
        return "lazy"

def read_full_stats_chunked(file_path: str, chunk_size: int = 10_000) -> dict:
    """Tính thống kê trên toàn bộ file CSV theo chunks.

    Args:
        file_path: Đường dẫn file CSV.
        chunk_size: Số rows mỗi chunk.

    Returns:
        Dict chứa min, max, mean, std, null_count, unique_count mỗi cột.
    """
    ...

def read_full_stats_lazy(file_path: str) -> dict:
    """Tính thống kê dùng polars lazy scan (không load RAM).

    Args:
        file_path: Đường dẫn file CSV hoặc Parquet.

    Returns:
        Dict chứa aggregated statistics.
    """
    import polars as pl
    lf = pl.scan_csv(file_path)
    return lf.select([
        pl.all().min().name.suffix("_min"),
        pl.all().max().name.suffix("_max"),
        pl.all().mean().name.suffix("_mean"),
        pl.all().null_count().name.suffix("_nulls"),
    ]).collect().to_dict()
```

## Multi-file Support

### Cú pháp

```bash
dataviz sales.csv customers.xlsx orders.parquet --join-on customer_id
```

### Pipeline

```
1. Reader Agent load schema của tất cả files
       │
       ▼
2. AI suy luận join keys (nếu không có --join-on)
       │
       ▼
3. Files được merge thành một DataFrame duy nhất
       │
       ▼
4. EDA + Viz pipeline chạy trên merged data
```

### Join types

| Flag | Join type | Default |
|---|---|---|
| (không chỉ định) | inner | ✅ |
| `--join-type left` | left join | |
| `--join-type outer` | outer join | |

### Auto join key inference

Khi không có `--join-on`, AI phân tích schema của các files và tự chọn join key:
- Tìm cột trùng tên giữa các files
- Ưu tiên cột có `id`, `key`, `code` trong tên
- Kiểm tra cardinality để xác nhận (unique ratio cao = potential key)

Nếu không thể xác định join key, agent báo lỗi rõ ràng và yêu cầu `--join-on`.

### XLSX Multi-sheet

```bash
dataviz data.xlsx --sheet "Q1 Sales"     # Sheet cụ thể
dataviz data.xlsx                         # Mặc định: sheet đầu tiên
```

Nếu file XLSX có nhiều sheet, TUI sẽ cho phép chọn sheet để phân tích.
